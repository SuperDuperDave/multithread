# Multithread brand assets

The identity was selected on 2026-09-19: direction "Plane", a measured field
under one light, with a mark that is the product's mechanism in four strokes.
A baseline is the main thread; an arc is a thread that leaves it and returns;
two nodes are where purpose and results stay connected.

| File | Use |
|---|---|
| `multithread-mark.svg` | The mark on its field, 64 × 64. Favicon, avatar, small badge. |
| `readme-banner.png` | The README header, 2400 × 760, rendered at 2× for sharp text. |
| `social-preview.png` | The repository's social preview, 1280 × 640. Upload it under **Settings → General → Social preview**; GitHub has no API for that field. |

Values: Field `#12102B`, Lit field `#2A2670`, Thread `#8B86FF` on the field and
`#4B44D6` on paper, Marks `#C9C6F0`, Paper `#F4F3FA`, Ink `#1F1C46`. Wordmark:
DM Sans 600 at −0.055em. The Mainthread product page carries the same identity:
https://mainthread.ai/work/multithread/

These files are documentation. They are not part of the runtime, the release
archive or the installer.
